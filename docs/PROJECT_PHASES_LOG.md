## 🔒 القواعد غير القابلة للتفاوض (Non-Negotiable Rules)
1. **الواقعية الصارمة:** التمييز القاطع بين التنفيذ الفعلي والمحاكاة أو القالب. إزالة أي نسب ثقة وهمية ثابتة (مثل 0.94 أو 0.96 الثابتة) وعرض «لم يُستخرج» مع السبب الحقيقي عند الفشل.
2. **فصل البيانات:** الاحتفاظ بالنص الخام من OCR، والنص المصحح بشريًا، واقتراح النموذج في حقول منفصلة غير مدمجة.
3. **حماية المراجع الأصلية:** عدم تعديل أو حذف أو نقل أداة `extract_unity_local` على `D:` بل التعامل معها كأصل محمي، ونسخها إلى مسار عمل مستقل `tools/extract_unity_local`.
4. **أمان المستودع:** عدم تضمين الفيديوهات الضخمة، أو أوزان النماذج الثقيلة، أو المفاتيح الحساسة في Git.
5. **التوثيق والاختبار:** لا يُعتمد تسليم أي مرحلة دون تشغيل اختبار فعلي وإثباته بسجلات حقيقية، ثم الرفع على GitHub بـ Commit واضح.
