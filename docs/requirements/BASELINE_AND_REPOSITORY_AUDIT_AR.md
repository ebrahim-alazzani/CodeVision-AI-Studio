## 3. تدقيق المستودعات المرجعية السبعة (`E:\repo exter vdio`)

### 1. `video2code-main (1)` — 🏆 الأهم والأعلى قيمة للمشروع
* **الغرض:** استخراج وإعادة بناء الكود من فيديوهات البرمجة المباشرة (Live Coding & Screencasts).
* **التقنيات:** Python, Pillow, PyTesseract, RapidFuzz. ترخيص **MIT صريح**.
* **الابتكار الأساسي:** تطبيق خوارزمية **ACE** الأكاديمية (ACM Onward! 2016):
  * استخراج المسافات البادئة هندسيًا (`Geometric Indentation`): حساب متوسط عرض الحرف `char_w = median(w / len)` وتحديد المسافات من الإحداثي السيني `left / char_w` بدقة متناهية دون الاعتماد على التخمين.
  * محاذاة الأسطر بالبرمجة الديناميكية (Needleman-Wunsch Alignment): حل مشكلة تحريك الشاشة (Scrolling) والكتابة التراكمية.
  * نظام التصويت الموزون بالثقة وحداثة التوقيت (`Confidence & Recency Weighted Voting`).
  * فحص البناء بمترجمات حقيقية (`py_compile`, `node --check`, `tsc`).
* **خطة الاستفادة:** دمج خوارزمية `consolidate.py` و `ocr_frames.py` داخل محرك CodeVision لإعادة بناء الأكواد المكتوبة والمتنقلة عبر الإطارات.

### 2. `shot2code-main` — 🌟 حلول متميزة لمعالجة الصور وتنقية الشوشرة
* **الغرض:** تحويل لقطات الشاشة البرمجية إلى كود نظيف وقابل للتشغيل.
* **التقنيات:** Tauri 2.0 (Rust) + React 18 + TypeScript + Tesseract.js WASM. ترخيص **MIT**.
* **الابتكار الأساسي:**
  * **معالجة مسبقة للإضاءة (`preprocessor.ts`):** فحص إضاءة 60 بكسل على أطراف الصورة لتحديد الثيم الداكن وعكسه إلى نص داكن على خلفية بيضاء نقية مع تكبير 2.0x، مما يرفع دقة Tesseract بأكثر من 20%.
  * **فلتر تنقية الأسطر (`codeHeuristics.ts`):** إزالة أرقام الأسطر الإحصائية (`1 |`, `02:`), إزالة علامات الطرفية (`$ `, `>>> `), وتصحيح الرموز البرمجية المزدوجة (`=>`, `->`).
* **خطة الاستفادة:** نقل منطق فحص الثيم الداكن وعكس الألوان وتجريد أرقام الأسطر إلى بايثون في مرحلة معالجة الإطارات.

### 3. `watch-skill-main` — 🏆 معمارية حديثة ومحرك RapidOCR ONNX
* **الغرض:** الفحص والإدراك متعدد الوسائط للفيديوهات والشاشات مع إثباتات تحقق صارمة.
* **التقنيات:** Python 3.11+, RapidOCR (PP-OCR ONNX), PySceneDetect, Faster-Whisper, FastEmbed, SQLite, FastMCP. ترخيص **MIT صريح**.
* **الابتكار الأساسي:**
  * تشغيل **RapidOCR عبر ONNX Runtime** مدمج دون الحاجة لتثبيت برمجيات خارجية لـ Tesseract على نظام ويندوز.
  * كشف المشاهد المزدوج (PySceneDetect ContentDetector + FFmpeg fallback).
  * خادم بروتوكول وكلاء الذكاء الاصطناعي (FastMCP Server) لربط الأداة بـ Cursor و Claude Desktop.
* **خطة الاستفادة:** اعتماد RapidOCR ONNX كخيار بديل فائق السرعة بدون تثبيت، وتوفير خادم MCP لـ CodeVision.

### 4. `videoscribe-main` — 🌟 دقة التوقيت وتفريغ صوتي خفيف الوزن
* **الغرض:** التفريغ الصوتي والقانوني للفيديوهات مع سرد بصري دقيق.
* **التقنيات:** Python, Faster-Whisper, NumPy. ترخيص **MIT صريح**.
* **الابتكار الأساسي:**
  * تحديد التوقيت بأرضية الثواني (`math.floor`) حصراً لتجنب انزياح التوقيت التراكمي في الفيديوهات الطويلة.
  * فصل المتحدثين الصوتي (Speaker Diarization) باستخدام **Pure NumPy** فقط دون تحميل مكتبات PyTorch أو PyAnnote الضخمة.
* **خطة الاستفادة:** اعتماد معايير التوقيت الدقيقة وتقنية فصل المتحدثين الخفيفة للتمييز بين صوت المحاضر والأسئلة في الورش البرمجية.

### 5. `watch-and-learn-main` — 🌟 إدارة ميزانية الإطارات والتكلفة
* **الغرض:** تمكين الوكلاء من التعلم واستخلاص المهارات من فيديوهات العمليات.
* **التقنيات:** Python Standard Library فقط (بدون أي مكتبات إضافية). ترخيص **MIT صريح**.
* **الابتكار الأساسي:**
  * خوارزمية **Auto-FPS Budgeting**: ضبط معدل الإطارات تكيفياً حسب مدة الفيديو (بحد أقصى 100 إطار للفيديوهات الطويلة) لمنع إرهاق المعالج واستهلاك الذاكرة.
  * تصفية الإطارات المتشابهة عبر مقارنة صور مصغرة 16x16 luma diff.
* **خطة الاستفادة:** تطبيق خوارزمية ضبط ميزانية الإطارات عند استيراد فيديوهات طويلة تتجاوز 30 دقيقة.

### 6. `vid2md-main`
* **الغرض:** تحويل الفيديوهات إلى وثائق ماركداون منظمة.
* **التقنيات:** Python, FFmpeg scdet, FunASR, Faster-Whisper.
* **الابتكار:** دمج تقطيع المشاهد البصرية مع فترات الصمت الصوتي (>3 ثوانٍ) لإنشاء فصول وعناوين منطقية للدروس.

### 7. `code-video-agent-main`
* **الغرض:** نموذج أولي لاستخراج الشفرات من يوتيوب عبر PaddleOCR.
* **التقييم:** كود ناقص (ملفات `config.py` و `reconstruct.py` غير موجودة، لا يوجد ملف ترخيص). غير مرشح للاستفادة المباشرة.
